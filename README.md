# -I-5G-V2X-Simulator
5G-V2X 관련 simulators

본 폴더는 과학기술정보통신부에서 주관하는 "초고속 V2X 통신기반 자율주행 서비스 기술 개발" 과제의 지원으로 구축되었습니다.

1. 과제개요
 - 주행협상 무결성 전송을 위한 Inter-Cell Interference Coordination(ICIC) 기술 개발
 - 주행협상 무결성 전송을 위한 Muting 기반 동적협력 CS-CoMP 기술 개발

2. 시뮬레이터
 - 3GPP에서 LTE-V2X 및 5G-V2X에 해당하는 TR 36.885와 38.885 시스템레벨 시뮬레이션 방법론을 준용하여 자원할당 및 QoS 관리 분석
